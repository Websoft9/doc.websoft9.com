## 入门指南{#guide}

### 初始化{#wizard}

1. Websoft9 控制台安装 Plex Media Server 后，通过 **我的应用** 查看应用详情，在 **访问** 标签页中获取访问 URL  

2. 本地浏览器访问 URL，它会跳转[Plex 官网](https://app.plex.tv)引导你注册

3. 完成注册后，你即可观看电视和电影节目了
