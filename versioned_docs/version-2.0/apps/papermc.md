## 入门指南{#guide}

### 连接使用

1. Websoft9 控制台安装 PaperMC 后，通过 **我的应用** 查看应用详情，在 **访问** 标签页中获取登录信息。

2. 本地电脑安装 [PCL](https://pcl.ruanmao.net/) 客户端

3. 在 PCL 平台上运行启动服务器相同的客户端版本， 选择加入**多人游戏** 模式

4. 输入 `服务器公网 IP:port` ，点击[加入服务器] 即可进入游戏
