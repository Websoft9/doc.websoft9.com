## 产品能力{#features}

[百智办公](https://work.baizhi.cloud/)是一款面向团队的开源 AI 办公工作台。用户可以用自然语言提出需求，让 AI 完成办公、编程与设计任务，并交付工作成果。

- **办公**：制作 PPT、编写文档、处理表格和整理文件。
- **编程**：参与架构设计、代码编写和问题修复。
- **设计**：支持海报制作、平面设计、交互设计和短剧制作。
- **团队协作**：共享大模型、知识库、技能、专家、MCP 和规则等资源。
- **统一管控**：提供资源使用与计费管理、权限控制、使用审计和团队使用统计。

:::note 版本说明

上述能力依据产品官网当前介绍整理。通过 Websoft9 部署时，应用名称、可用功能和访问方式以应用商店提供的具体版本为准。

:::

## 入门指南{#guide}

### 登录后台{#console}

通过 Websoft9 控制台安装对应应用后，在 **我的应用** 中查看应用详情，通过 **访问** 标签页获取访问入口和登录信息。

### 开始使用{#usage}

打开对应实例的 Web 入口，或从[官网](https://work.baizhi.cloud/)获取当前可用的客户端，按照[产品文档](https://work.docs.baizhi.cloud/)配置访问。

提供相关文件，用自然语言说明任务目标和交付要求，例如整理汇报 PPT、分析表格、编写代码或制作海报。任务完成后，检查生成的成果是否符合要求。

## 配置选项{#configs}

- **团队资源**：按团队需要共享模型、知识库、技能、专家、MCP 和规则。
- **模型与工具**：接入团队选择的模型服务和业务工具，具体配置参阅[产品文档](https://work.docs.baizhi.cloud/)。
- **客户端**：支持 Web 和桌面客户端；当前支持的平台及下载入口以[官网](https://work.baizhi.cloud/)为准，尚未发布的平台不视为已支持。

## 管理维护{#administrator}

百智办公支持私有化部署，团队可以将消息、文档与项目保存在自己的服务器上，自主管理访问权限、数据备份与保留策略，并安排升级和维护。

通过企业管理面板统一管理团队资源、访问权限与使用情况，进行资源使用与计费管理、使用审计和统计。独立部署与配置方法参阅[官方产品文档](https://work.docs.baizhi.cloud/)。

## 故障{#troubleshooting}

- **部署与访问问题**：先核对 Websoft9 **我的应用** 中的应用状态、访问入口和实际部署版本。
- **产品使用与配置问题**：查阅[官方产品文档](https://work.docs.baizhi.cloud/)，或在[官方代码仓库](https://github.com/chaitin/monkeycode)反馈问题。
