[Databasus](https://databasus.com) 是一个 **数据库备份工具**，它被用于 数据库工具  等场景。Databasus 是一个针对 MySQL、PostgreSQL 和 MongoDB 数据库的开源性能监控与可视化平台。


![界面](https://libs.websoft9.com/Websoft9/DocsPicture/zh/databasus/databasus-gui-websoft9.png)


## 准备

在参阅本文档使用 Databasus 时，需要确保如下几点：

- [登录 Websoft9 控制台](./login-console)，然后找到（或安装）Databasus：
  - **我的应用** 菜单找到应用 
  - **应用商店** 菜单部署应用

- 应用是基于 Websoft9 安装的


- 应用的用途符合 [apache2](https://opensource.org/licenses/Apache-2.0) 开源许可协议


- 为应用准备配置访问方式：[配置域名](./domain-set) 或 **服务器安全组**开启网外端口
