[SafeLine](https://safepoint.cloud/) is **Open source WAF**, used for Detection and Monitor . SafeLine is a self-hosted WAF(Web Application Firewall) to protect your web apps from attacks and exploits.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/safeline/safeline-gui-websoft9.png)


## Prepare

When referring to this document to use **SafeLine**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install SafeLine:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [GPL-3.0](https://opensource.org/licenses/GPL-3.0) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
