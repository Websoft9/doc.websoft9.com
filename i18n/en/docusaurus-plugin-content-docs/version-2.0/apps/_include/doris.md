[Doris](https://doris.apache.org/) is **data warehouse for real-time analytics**, used for Data Warehouse and Lake . Doris is a modern data warehouse for real-time analytics.It delivers lightning-fast analytics on real-time data at scale.

## Prepare

When referring to this document to use **Doris**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Doris:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [apache2](https://opensource.org/licenses/Apache-2.0) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
