[OpenClaw](https://openclaw.ai/) is **Personal AI Assistant**, used for AI Agents/Chatbots/RAG . OpenClaw is a personal AI assistant you run on your own devices


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/openclaw/openclaw-gui-websoft9.jpg)


## Prepare

When referring to this document to use **OpenClaw**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install OpenClaw:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [MIT](https://opensource.org/licenses/MIT) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
