[Appwrite](https://appwrite.io) is **Backend as a Service Platform**, used for Low Code and No Code . Appwrite is an open-source, self-hosted backend platform that provides integrated APIs for authentication, database, storage, functions, and more, empowering developers to build applications quickly.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/appwrite/appwrite-gui-websoft9.png)


## Prepare

When referring to this document to use **Appwrite**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Appwrite:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [bsd3Clause](https://opensource.org/licenses/BSD-3-Clause) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
