[Databasus](https://databasus.com) is **backup databases tool**, used for Database Management Tools . Databasus is an open-source performance monitoring and visualization platform for MySQL, PostgreSQL, and MongoDB databases.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/databasus/databasus-gui-websoft9.png)


## Prepare

When referring to this document to use **Databasus**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Databasus:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [apache2](https://opensource.org/licenses/Apache-2.0) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
