[Hyperswitch](https://hyperswitch.io/) is **Open Source Payments Platform**, used for Subscriptions and billing . Hyperswitch is an open-source payment routing platform that integrates multiple payment gateways, enhances transaction success rates, reduces costs, and provides highly customized payment solutions for global enterprises.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/hyperswitch/hyperswitch-gui-websoft9.png)


## Prepare

When referring to this document to use **Hyperswitch**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Hyperswitch:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [apache2](https://opensource.org/licenses/Apache-2.0) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
