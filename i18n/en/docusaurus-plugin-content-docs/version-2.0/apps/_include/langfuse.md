[Langfuse](https://langfuse.com) is **open source LLM engineering platform**, used for AI Agents/Chatbots/RAG AI DevOps . Langfuse is an open source LLM engineering platform. It helps teams collaboratively develop, monitor, evaluate, and debug AI applications. Langfuse can be self-hosted in minutes and is battle-tested.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/langfuse/langfuse-gui-websoft9.png)


## Prepare

When referring to this document to use **Langfuse**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Langfuse:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [MIT](https://opensource.org/licenses/MIT) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
