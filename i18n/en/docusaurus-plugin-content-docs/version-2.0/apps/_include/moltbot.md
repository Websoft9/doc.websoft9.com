[Moltbot](https://clawd.bot/) is **Personal AI Assistant**, used for AI Agents/Chatbots/RAG AI DevOps . Moltbot is an open-source, self-deployable "personal AI assistant" with the core feature of enabling AI to "do things" rather than just answer questions.


![gui](https://libs.websoft9.com/Websoft9/DocsPicture/zh/moltbot/moltbot-gui-websoft9.png)


## Prepare

When referring to this document to use **Moltbot**, please read and ensure the following points:

- [Login to Websoft9 Console](./login-console) and find or install Moltbot:
  - Go to **My Apps** listing applications 
  - Go to **App Store** installing target application

- This application is installed by Websoft9 console.


- The purpose of this application complies with the [MIT](https://opensource.org/licenses/MIT) open source license agreement.


- [Configure the domain name](./domain-set) or **server security group** opens external network ports for application access.
