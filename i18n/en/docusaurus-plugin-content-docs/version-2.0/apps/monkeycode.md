## Product capabilities{#features}

[百智办公 (MonkeyAI)](https://work.baizhi.cloud/) is an open-source AI workspace for teams. Users describe their requirements in natural language and let AI carry out office, coding, and design tasks to deliver work products.

- **Office work**: Create presentations, write documents, process spreadsheets, and organize files.
- **Coding**: Assist with architecture design, code writing, and issue resolution.
- **Design**: Create posters, graphic designs, interaction designs, and short dramas.
- **Team collaboration**: Share models, knowledge bases, skills, experts, MCP resources, and rules.
- **Centralized management**: Manage resource usage and billing, permissions, usage audits, and team usage statistics.

:::note Version scope

These capabilities summarize the current product website. For Websoft9 deployments, the application name, available features, and access methods depend on the specific version offered in the application store.

:::

## Getting started{#guide}

### Login verification{#verification}

After installing the corresponding application through the Websoft9 console, open its details in **My Apps** and use the **Access** tab to obtain the access URL and login information.

### Start using the workspace{#usage}

Open the Web interface of your instance, or download an available client from the [product website](https://work.baizhi.cloud/). Follow the [product documentation](https://work.docs.baizhi.cloud/) to configure access.

Provide relevant files and describe the task goal and expected deliverables in natural language, such as preparing a presentation, analyzing a spreadsheet, writing code, or creating a poster. Review the generated work when the task finishes.

## Configuration options{#configs}

- **Team resources**: Share models, knowledge bases, skills, experts, MCP resources, and rules as needed.
- **Models and tools**: Connect the team's chosen model services and business tools. See the [product documentation](https://work.docs.baizhi.cloud/) for configuration details.
- **Clients**: Web and desktop clients are supported. Check the [product website](https://work.baizhi.cloud/) for currently available platforms and downloads; unreleased platforms are not treated as supported.

## Administer{#administrator}

The workspace supports self-hosting. Teams can store messages, documents, and projects on their own servers, manage access permissions, backups, and retention policies, and schedule upgrades and maintenance.

Use the enterprise management panel to manage team resources, permissions, and usage, including resource usage and billing, usage audits, and statistics. See the [official product documentation](https://work.docs.baizhi.cloud/) for deployment and configuration instructions.

## Troubleshooting{#troubleshooting}

- **Deployment and access issues**: First check the application status, access URL, and deployed version in Websoft9 **My Apps**.
- **Product usage and configuration issues**: Consult the [official product documentation](https://work.docs.baizhi.cloud/) or report issues in the [official code repository](https://github.com/chaitin/monkeycode).
